# Basilisk
[![Build](https://github.com/PacIFiC-Development-Team/basilisk/actions/workflows/build.yml/badge.svg)](https://github.com/PacIFiC-Development-Team/basilisk/actions/workflows/build.yml)

The repo here is a vendored version of the [basilisk](basilisk.fr) software suite with some minor portability enhancements to `qcc` and a CMake build system to help integration with the [PacIFiC](https://github.com/anthonywachs/pacific) project with components of the project using Basilisk.
